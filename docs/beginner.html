EverChat source map

A short summary of each module in src/ (tests not included), and a map of who imports whom. Use it to choose what to read, and what to improve, first.

How to read the map

Each box is one file. An arrow from A to B means A imports B. Columns go from left to right. The left column imports nothing of ours that runs, so you can read those files alone. Each column to the right builds on the columns before it. So read from left to right.

Click a box (or press Tab and Enter) to see its summary. Its imports turn orange, and the files that import it turn blue. A dot on a box means it has known work to do.

Click a box to see what the file does.

Where to start

  1. Warm up with the small files that stand alone. names, price, clip, theme, and pick. Each is under 150 lines and imports nothing that runs.
  2. Learn the core idea, in this order. Read docs/references/optchat.md first. Then clip (text sizes), config and disk (settings and durable writes), askai (model calls and the prompt cache), agent (the call loop), memory (the tree and the view), and tools (the prompts). Skim anthropic and openai, which are vendor formats.
  3. Read server last. It joins everything, and it is 2190 lines. Read one section at a time, starting with turns (Chat.take).
  4. Good first improvements, from docs/upstream-issues-and-prs.md. Each one is small and has a clear test.
    • machine: the abort-listener leak in Machine.nap.
    • agent: the abort-listener leak in Agent.yielded.
    • md: numbered lists and sub-lists (upstream #16, PR #22).
    • openai: check how a stream error event is read (from PR #33).
  5. The first change to the core: a separate system prompt for compactions (upstream PR #37). It touches tools, memory, server, and src/prompt.txt. Do it after step 2.

All modules

The map is built from the import lines of src/*.ts as of 2026-11-05 (commit fe1742d). It does not update itself, so it goes out of date when the imports change. Only value imports decide the columns. A type-only import (dashed) brings in only types, so it can point right or form a cycle without changing the reading order. A dotted line is a lazy import (await import), loaded only when needed. The browser code in web/src/ also uses call, import, md, theme, and view. It is not on the map.
